# 📊 Urban Threads Sales Dashboard

## Dashboard Preview

![Dashboard](DASHBOARD%20FINAL.png)

## 📌 Project Overview

This interactive Excel dashboard analyzes Urban Threads sales data using Pivot Tables, Pivot Charts, KPIs, and Slicers to provide business insights.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## 📈 Dashboard Highlights

- Total Sales
- Total Orders
- Total Profit
- Sales by Category
- Interactive Filters
